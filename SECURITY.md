# Security policy

Report suspected vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/oschwald/maxminddb-polars/security/advisories/new).
Do not open a public issue, pull request, or discussion containing exploit
details or sensitive data.

Include reproduction steps, affected versions, impact, and any proposed
mitigation. Maintainers will acknowledge reports as soon as practical and will
coordinate disclosure after a fix or mitigation is available.

We support only the latest published release.
